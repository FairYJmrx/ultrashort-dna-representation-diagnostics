# 35-species CAMISIM panel

`species_panel.csv` is the small, non-patient metadata subset used to prepare
the CAMISIM input tables. It contains one representative assembly per species
for the 35-species benchmark. `label_map.json` uses the alphabetical species
order observed in the generated 75-bp label cache.

Reference FASTA files, CAMISIM outputs and FASTQ files are not distributed in
this directory. Their paths, sizes and SHA-256 values belong in the generated
run manifest.
