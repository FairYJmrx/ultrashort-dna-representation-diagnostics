\section{Data Availability}

All processed data tables, figure source summaries and analysis outputs generated for this study are maintained in a \href{https://github.com/FairYJmrx/ultrashort-dna-representation-diagnostics/tree/release}{private GitHub review repository} on the \texttt{release} branch. Reviewer access will be provided through the submission system or by adding a journal-supplied account as a read-only collaborator. A public archival DOI will be minted from the frozen release when the authors make the repository public.

Publicly reused resources include simulator- and benchmark-derived materials used for the shared-template WGS continuity audit, ART, CAMI\_TOY\_low and CAMI II marine analyses \citep{Huang2012ART,Sczyrba2017,Meyer2022}. The review repository contains the 420-template continuity manifest, compressed perturbation summaries, local-triplet results, ART generation manifests and quality-stratified summaries. The CAMI II marine lightweight probe used the public CAMI II marine short-read sample 0 reads archive and its corresponding setup archive; exact resource URLs are listed in the review-access repository and will be retained in the public archived release. Only a streamed prefix was parsed for the lightweight stability probe, and read-level taxonomic labels were not reconstructed from the separate truth resources for this analysis. Local restricted sequencing records were used only as aggregate read-length provenance for the 69 and 75 bp conditions. The underlying clinical sequencing reads were not used as experimental input, are not part of the study data package, and cannot be publicly shared.

\section{Ethics and Data Governance}

No patient-level clinical sequencing reads, patient identifiers or patient-derived labels were analysed. Public reference sequences and benchmark-derived reads were the only sequence-level experimental inputs. Restricted local sequencing records contributed only aggregate read-length provenance for the 69 and 75 bp conditions; no local read sequence or clinical outcome entered an analysis.
