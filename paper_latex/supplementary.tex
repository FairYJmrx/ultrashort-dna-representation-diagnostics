\section{Supplementary data overview}
The canonical 4-mer, property and multi-scale property-pooling representation (CK4P-MSP) comprises a canonical 4-mer composition block (K), a global property block (P) and multi-scale property pooling (MSP). Figures S1--S7 report reduction, information-estimator, perturbation, counterfactual, parameter and dimension-matched baseline audits. Figures S8--S14 cover P/MSP relations, external stability, mechanism, historical descriptors, read-length continuity and fixed-head transfer. Figure S15 reports the supplementary CK4P-MSP-PKM positional-readout Pareto audit. Tables S1--S10 provide the corresponding dataset previews, contrasts, estimator checks, feature definitions, accessions, target metadata and coordinate-family attribution. Unless otherwise stated, plots show analysis-cell means without error bars. Cell-bootstrap intervals summarize prespecified matched cells that reuse source template panels and therefore do not represent independent biological cohorts.

\section{Supplementary Methods: positional k-mer moment extension}

CK4P-MSP-PKM was evaluated as a supplementary positional-moment extension of CK4P-MSP. For a read with $T=L-k+1$ valid $k$-mer windows, the centre of window $t$ was assigned a normalized relative coordinate $u_t\in[-1,1]$. Let $c_t$ denote the reverse-complement canonical 4-mer at that window and let
\[
\mathbf{b}(u_t)
=
\left[
u_t,\;
\frac{3u_t^2-1}{2},\;
\frac{5u_t^3-3u_t}{2}
\right]
\]
be the first three non-constant Legendre-style position basis functions. The uncompressed positional k-mer moment array was
\[
R_i(c,q)
=
\sum_{t=1}^{T}
\mathbb{1}(c_t=c)\,b_q(u_t),
\]
where $c$ indexes the 136 canonical 4-mers and $q\in\{1,2,3\}$. A deterministic signed hash with seed 20260805 mapped the 408 token-moment coordinates to a 75-dimensional vector, which was row-normalized to give $\hat{\mathbf{Z}}_i$. Invalid windows containing ambiguous bases contributed zero to the moment array.

The supplementary extension retained the normalized CK4P-MSP blocks and appended PKM as
\[
\mathbf{x}^{\mathrm{PKM}}_i
=
\frac{1}{\sqrt{3+\delta^2}}
\left[
\hat{\mathbf{K}}_i\,;\,
\hat{\mathbf{P}}_i\,;\,
\hat{\mathbf{M}}_i\,;\,
\delta\hat{\mathbf{Z}}_i
\right].
\]
The fixed grid $\delta\in\{0.1,0.25,0.5,0.75,1\}$ was declared before the exploratory sweep. Among the tested weights, $\delta=0.25$ met the prespecified screen for motif-position gain, bounded WGS/ART drift change, retained nearest-clean retrieval, local-change readout, CAMI fixed-head retention and less than twofold reference extraction time. It is reported as the exploratory CK4P-MSP-PKM Pareto setting.

The sweep reused the WGS, local-change, public Dorsal motif-position, ART and CAMI resources defined in the main Methods. The motif-position probe comprised 1,125 windows from 32 cis-regulatory modules, and all windows from one module were retained in the same cross-validation fold. A seed-20260819 resampling check quantified seed sensitivity within the same benchmark resources. Runtime used two actual 10,000-read batches, and the direction audit used 5,000 clean/reverse-complement pairs. Because odd position moments reverse sign, CK4P-MSP-PKM is input-order-sensitive; only its CK4 block is canonicalized. Historical descriptors were evaluated under the same sampled protocol to position the extension within the observed stability--readout--cost trade-offs.
