| representation              | definition                                                                                  | information emphasized                                                     | strength region                                               | limitation                                                                    |
|:----------------------------|:--------------------------------------------------------------------------------------------|:---------------------------------------------------------------------------|:--------------------------------------------------------------|:------------------------------------------------------------------------------|
| 5-mer count                 | Counts contiguous length-5 words and L2-normalizes the vector.                              | local composition and exact short words                                    | simple composition probes and strong conventional baseline    | not strand-invariant unless canonicalized; vocabulary grows as 4^k            |
| canonical 5-mer             | Counts min(word, reverse-complement word) for each 5-mer.                                   | strand-symmetric local composition                                         | close-relative classification stress tests                    | may discard strand-specific signals and remains high-dimensional for larger k |
| canonical spaced            | Counts spaced-seed tokens after reverse-complement canonicalization.                        | non-contiguous local patterns with strand symmetry                         | compact strand-friendly baseline                              | less exact than contiguous k-mer for some close-relative tasks                |
| canonical spaced + property | Concatenates canonical spaced-token counts with DNA property summaries, then L2-normalizes. | strand symmetry plus GC, purine, hydrogen-bond, EIIP, and N-mask summaries | compact auxiliary representation with perturbation stability  | not a universal replacement for canonical k-mer                               |
| property channels           | Maps each base to biochemical/numeric channels along sequence position.                     | per-position biochemical signal and ambiguity masks                        | substitution-stability and model-compatible dense input       | weak taxonomy signal without a model that uses positional context             |
| spaced property + phase     | Uses spaced-token property vectors with explicit three-phase positional sine/cosine terms.  | spaced local signal plus reading-frame-like phase prior                    | position-sensitive controlled tasks                           | current ablation did not show independent phase gain                          |
| RoPE property               | Rotates DNA property channels with RoPE-like relative positional phases.                    | attention-compatible property and relative-position signal                 | hypothesis-driven input for tiny Transformer/server follow-up | not yet validated with a full Transformer in this local study                 |
